# BOSS 直聘岗位采集插件

让阿渔在对话里直接读你正在看的 BOSS 直聘页面，返回结构化岗位数据；需要时会逐条打开详情页读 JD，再汇总成一份 Markdown 报告。

## 装

在 DSH 的 Plugins 页面添加：

```
https://github.com/Archer1045/dsh-boss-job-collector
```

或本地开发用绝对路径。

## 用之前要做一件事

浏览器必须带调试端口启动，否则插件连不上：

```powershell
& "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --remote-debugging-port=9222 --user-data-dir="C:\Users\<你>\AppData\Local\Microsoft\Edge\User"
```

用你自己的 `--user-data-dir`，登录态才在。启动后打开 BOSS 搜索结果页，等卡片渲染出来。

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `batches` | 3 | 滚动加载几批，每批约 15 条 |
| `withDetail` | false | 是否逐条打开详情页读 JD |
| `detailLimit` | 20 | 最多读几条详情，上限 20 |
| `detailOffset` | 0 | 从第几条开始读，用于分两批跑 |
| `port` | 9222 | 调试端口 |
| `scrollWaitMs` | 1200 | 每批滚动后等待毫秒数 |

## 会做什么

- 读当前已渲染的岗位卡片：职位、薪资、公司、地区、经验、学历、标签、链接
- 薪资的私有区字符（PUA）还原成数字，识别 `20-30K`、`40-70K·15薪`、`500-550元/天` 三种格式
- `withDetail` 时后台开标签页读 `.job-detail-body`，读完即关；连续 3 条失败或遇到验证码就停
- 技能按 58 条六类词典抽取，按**去重岗位数**统计，不是按出现次数

## 不会做什么

- 不自动翻页、不调内部接口、不带 Cookie
- 不滚动整页到死（页面高度不增长就停）
- 不写数据库、不上传任何数据
- 详情页里没有的字段不编造

## 已知限制

- **必须**由你手动用 `--remote-debugging-port` 启动浏览器
- 风控降级时薪资会变成占位符，此时标 `salary_unverified`，不参与统计
- 只读已渲染到 DOM 的卡片，没滚出来的看不到
- 跨机器迁移需要重新配浏览器启动参数，**未在第二台机器实测**
- 扩展侧（`extension/`）与本插件共用同一份适配器实现，但扩展是独立加载的

## 排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `请先用 --remote-debugging-port 启动浏览器` | 浏览器没开调试端口 | 按上面的命令重启浏览器 |
| 工具在列表里但调用报错 | 页面不是列表页 | 打开 BOSS 搜索结果页再试 |
| 薪资显示为占位符 | 风控降级 | 手动刷新页面，或换正常浏览器窗口 |
| 装了插件但工具没出现 | 会话启动时工具列表已定死 | 重启 DSH，新开会话 |

## 它会被怎么调用

会话开始时插件会往系统提示注入一段约定：涉及 BOSS 岗位数据时，必须先调 `collect_boss_jobs` 读真实页面，不许凭常识编造岗位名、薪资或公司。所以正常情况你只需要说「扫一下现在这个 BOSS 页面，滚两批」。

## 常见问题

**为什么不能直接点卡片展开详情？**
BOSS 列表页点卡片是整页跳转，不是内嵌面板。插件改成后台开标签页读、读完关掉，不抢你的焦点。

**技能统计为什么按岗位数？**
一个 JD 里提到 5 次 Redis 不代表它比只提 1 次的 Python 更重要，按岗位出现率才反映「这类岗位普遍要求什么」。

**JD 全文存哪了？**
`reports/raw/boss-jobs-<时间>.json`，只把路径返回给对话，避免把几万字塞进上下文。
